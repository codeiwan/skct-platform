# SKCT Platform

A self-hosted SKCT practice platform with timed mock exams,
automated scoring, and performance analytics.

## Overview

SKCT Platform is a web-based practice and performance tracking
system designed for SKCT preparation.

The platform will provide:

- Timed mock examinations
- Automated scoring
- Question-level performance tracking
- Personal score analytics
- User authentication and administration

## Tech Stack

- Backend: Python, FastAPI
- Frontend: TypeScript, HTML, CSS
- Database: SQLite
- Deployment: Docker

## Development Status

The project is currently in the initial development stage.
